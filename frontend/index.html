How this connects to the measured study

This browser simulator applies the same H, RZ and ZZ gates as the Python feature map, using 16 complex amplitudes. Its exact overlap is validated against Qiskit. The decision regions use the exported classical SVM trained with the primary exact ring kernel. Changing the encoding hides that fixed classifier. Finite-shot sampling here uses the ideal overlap and a seeded browser RNG. It does not simulate processor noise or replace the saved Aer measurements.

Measurement and correction details

The kernel uses 3,240 upper-triangle training pairs including diagonals and 1,600 held-out pairs. Counts are mirrored for the training matrix. Raw error is measured against the exact reference. The noisy SVM uses the positive training eigenspace and a consistent held-out extension. Its feature map and C stay frozen across all six shown conditions. Noisy diagonals are measured, not forced to one.

Scope and limits

This is a four-qubit experiment on 100 synthetic points. It demonstrates neither quantum speedup nor population superiority. Noise uses matched depolarizing parameters 0.001 for native single-qubit gates and 0.005 for CX, plus independent readout error 0.01. No physical quantum processor is accessed. Simulator timing is not hardware timing. All unfavorable results remain visible.
